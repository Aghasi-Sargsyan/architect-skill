## v3.30 / 1.8 (2026-11-03 — Cycle 18: Team Mode v1, Personal Local Config, Merge-Aware Gate, and Linux Check Support)
- **Team mode switch (`--init --team`, `"team": true`), `references/team.md`, and `templates/github-team-ci.yml` (`ADR-043`, `SKILL.md` `v3.30`, `config.mjs`, `cli.mjs`):** Added explicit `"team": true` opt-in in shared project config (`--init --team`), keeping the solo workflow untouched and never triggering strict team checks via `CI=true`. Added `references/team.md` (referenced via a single link in `SKILL.md` §1 so core size grows by only `92` bytes, `27689` → `27781` bytes `<= 34 KB`) and stack-neutral `templates/github-team-ci.yml` (`ubuntu-latest`, Node 22, two-tier PR task gate on `cycle/*` vs full `fullTestCommand` + `--self-check` on `master`/`main`).
- **Personal gitignored config overlay and model source chain (`ADR-044`, `layout.mjs`, `config.mjs`, `hooks.mjs`, `check.mjs`):** Added `.architect/config.local.json` and `.agents/orchestrator.local.json` overlay for personal environment settings (`executor`, `architect`, `auditor`, `runner`, `runnerBin`, `agyBin`, `notify`), rejecting project policy fields in `.local.json` fail-closed. `--check` reports the resolved Executor model and its relative source (`.local.json` → shared config → agent file). Added `.github/workflows/**`, `CODEOWNERS`, and `*.local.json` to `alwaysFrozenFiles` / `isAlwaysFrozenFile`.
- **Base-plan task gate, `merge-base` diffing, merge-commit history, and squash detection (`ADR-045`, `git.mjs`, `hooks.mjs`, `mechanics.mjs`, `selfcheck.mjs`, `cli.mjs`):** `runCheckTask` reads `PLAN.md` from `<base>:PLAN.md` (rejecting any `PLAN.md` edit on the task branch), computes diffs and commits from `git merge-base <base> HEAD` (supporting both task branches behind `cycle/<N>` and GitHub Actions synthetic `refs/pull/N/merge`), and executes the task's `Verify` commands from `<base>:PLAN.md`. `resolveBaseShaForTask` and `resolveSelfCheckBase` fail closed with a `fetch-depth: 0` hint when `--base` cannot be resolved. `--self-check` and `--check-task` handle merge-commit histories (`--no-ff`) and detect squash merges (counting `(#N)` in subject only alongside another squash indicator).
- **Parallel task fields, overlap check, Linux check support, and GitHub settings guide (`ADR-046`, `plan.mjs`, `README.md`, `README.en.md`, `README.ru.md`, `.github/workflows/ci.yml`):** Added `Executor: @<github-handle> · <Environment> · <Model>` (refusing execution when the assigned environment mismatches local `runner`) and `Parallel with: T-MMM` with mechanical non-overlap verification (`Change`, `Frozen`, `referenceTests`); added `ubuntu-latest` to the skill CI matrix for `--check`, `--check-task`, and `--self-check`; added Section 9 (`Team Use and GitHub Repository Settings`) with exact GitHub Rulesets and official documentation links.
- **Field fixes and one-command self-update (`/architect update` and `--update`, `ADR-047`, `ADR-048`, `SKILL.md`, `update.mjs`, `permissions.mjs`, `prompts.mjs`, `plan.mjs`, `mechanics.mjs`, `check.mjs`, `selfcheck.mjs`, `evidence.mjs`):** Added `--update` in the orchestrator and `/architect update` in `SKILL.md` Step 0 (`27776` → `28135` bytes `<= 34 KB`, justified by eliminating manual multi-step skill updates across projects), auto-refusal with `suggestedCommand` for `npx grep`/`npx ls`/`npm list`, scoped `.skip`/`.only` detection to test-runner calls, glob support in `## Frozen`, and cycle-closure retrospective verification in `selfcheck.mjs`.

- **First-run onboarding and Markdown model normalization (`SKILL.md` `v3.29`, `references/orchestrator.md`, `hooks.mjs`, `MAINTAINING.md`):**

- **Behavioral eval scenario `first_run_no_executor_model` (`ADR-042`, `evals-scenarios.mjs`, `evals.mjs`, `evals-fixtures.test.mjs`):** Added the 6th behavioral eval scenario testing a fresh project without `EXECUTOR.md` and without an Executor model (`PASS` only when the Architect asks the user for the Executor model, does not pick it on its own, and writes no files before approval).
