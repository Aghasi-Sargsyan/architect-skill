# Architect Lite (`v0.1`)

Одностраничная версия скилла «Архитектор» для случая, когда одна сильная модель и проектирует, и пишет код. В ней нет роли Исполнителя, карточек задач `PLAN.md` и оркестратора. English guide: [README.md](README.md).

В репозитории два независимых скилла: полный [`architect`](https://github.com/Aghasi-Sargsyan/architect-skill) и этот. Можно поставить любой из них или оба; у каждого своя команда установки и обновления.

## Что он делает

1. **Согласование до кода.** Модель читает журнал решений и нужный код, предлагает два-три варианта с их ценой и не меняет файлы, пока вы не одобрите один из них.
2. **Журнал решений.** Каждое проектное решение записывается в `docs/decisions.md`: одной строкой, если оно обратимо, и короткой записью (что выбрали, что отвергли, почему, когда пересмотреть), если откат дорогой.
3. **Зоны риска.** Для денег, доступов, миграций, конкурентности и персональных данных тесты с ожидаемыми результатами пишутся до реализации и не подгоняются под код.
4. **Честное завершение.** Работа готова, когда команда проверки запущена и прошла. Всё остальное помечается `NOT VERIFIED`.

## Установка

Запускайте в корне своего проекта. Команды можно повторять: повторный запуск обновляет скилл.

- **Claude Code (`.claude/skills/`):**
  ```bash
  tmp=$(mktemp -d) && git clone --depth 1 https://github.com/Aghasi-Sargsyan/architect-skill.git "$tmp" && mkdir -p .claude/skills && rm -rf .claude/skills/architect-lite && cp -R "$tmp/lite/architect-lite" .claude/skills/ && rm -rf "$tmp"
  ```
- **Codex, Cursor, Gemini CLI, Antigravity (`.agents/skills/`):**
  ```bash
  tmp=$(mktemp -d) && git clone --depth 1 https://github.com/Aghasi-Sargsyan/architect-skill.git "$tmp" && mkdir -p .agents/skills && rm -rf .agents/skills/architect-lite && cp -R "$tmp/lite/architect-lite" .agents/skills/ && rm -rf "$tmp"
  ```

## Обновление

Повторите команду установки для своего агента. Она заменяет папку скилла последней версией из репозитория и больше ничего не трогает: блок правил в вашем `AGENTS.md` и ваш `docs/decisions.md` остаются как есть. После обновления сравните свой блок с `templates/agents-block.md` и перенесите новые правила вручную.

Команды полного скилла `/architect update` и `--update` этот скилл не обновляют, а эта команда не обновляет полный. Чтобы удалить скилл, удалите его папку.

## Использование

1. Напишите `/architect-lite <что хотите сделать>` (или попросите агента прочитать `SKILL.md` в папке скилла).
2. При первом запуске модель предложит добавить блок из [templates/agents-block.md](templates/agents-block.md) в ваш `AGENTS.md`, `CLAUDE.md` или `GEMINI.md`. Заполните два места: свои зоны риска и свою команду проверки. Этот блок держит правила активными в каждой сессии, в том числе там, где вы скилл не вызывали.

## Когда использовать

- **Нужен**, если проект проживёт дольше пары недель, если фича затрагивает данные, доступы или деньги, или если прежние решения начали противоречить друг другу.
- **Не нужен** для прототипа, MVP по готовому образцу, мелкой правки и чисто визуальной работы.
- **Полный скилл [`architect`](https://github.com/Aghasi-Sargsyan/architect-skill) вместо него** — когда код пишет более дешёвая модель, когда цикл работает без присмотра или когда команде нужен след ревью. Оба скилла можно установить рядом.
