# Architect Lite — правила для агентов

Одностраничный скилл для работы одной моделью. Папка `architect-lite/` целиком копируется в проекты (`SKILL.md`, `templates/agents-block.md`). `README.md` и `README.ru.md` в корне — руководство для людей, в проекты они не попадают.

- **Ничего проектного.** Скилл используется в очень разных проектах. В `SKILL.md` и в шаблон блока не попадают пути, команды и договорённости конкретного проекта: их место в `AGENTS.md` того проекта.
- **Одна страница.** Скилл ценен краткостью. Новое правило добавляется, когда пробел проявился в работе, а не заранее.
- **Язык.** Общение с пользователем — на русском. `SKILL.md`, шаблон блока и сообщения коммитов — на английском. `README.md` и `README.ru.md` меняются вместе и говорят одно и то же.
- **Версии.** При правке правил в `SKILL.md` подними версию в его заголовке `# Architect Prompt vX.Y (Lite)` и в заголовках обоих README, добавь строку в раздел «Изменения». При правке шаблона блока подними ещё и `architect-lite-block-version`: по этой строке скилл предлагает проектам обновить блок.
- **Проверка.** Тестов нет. После правки команды установки или раскладки файлов выполни команду из README в пустой папке и убедись, что в `.claude/skills/architect-lite` лежат `SKILL.md` и `templates/agents-block.md`. Чего не запускал, называй `NOT VERIFIED`.
- **Git.** Коммиты с явными путями (`git add <пути>`), без `git add .` и `git add -A`. `git push` — только по прямой команде пользователя в текущей сессии. `git reset --hard`, force push и переписывание истории — только с разрешения пользователя.
