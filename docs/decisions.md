# Архитектурные решения (ADR)

- **ADR-008:** Защиты оркестратора (`PATH`-обёртки, хук `pre-push`, `pushurl`, allowlist, `checkExecutorRun`) защищают от ошибок и обходов правил моделью, но не видят временных изменений внутри хода (`A4`, например правка и откат теста при `npm test`); изоляция от prompt injection закладывается как песочница раннера в интерфейс адаптера `D2`, а проекты с недоверенными данными запускают цикл в ОС-песочнице/контейнере или отдельном клоне без сетевых/облачных ключей (Цикл 4 / S1).
- **ADR-009:** `commandProblem` (`permissions.mjs`) разворачивает командные обёртки (`time`, `timeout`, `nice`, `nohup`, `caffeinate`, `stdbuf`, `command`, `builtin`, `arch`) и нормализует бинарники по `basename`, отклоняя обёртки, пути с `/`, `--output` в `git`, `git branch` кроме `--show-current` и вызовы `python`/`python3` кроме `-m pytest` / `-m unittest`; вариант «1 — Всегда» в `proposeRules` предлагается только для белого списка известных инструментов стеков (Цикл 4 / S1).
- **ADR-010:** Механические защиты оркестратора и git-обёртки: `commitsSince` использует `git show --name-only --no-renames`; `parsePlan` распознаёт заголовки `/^(frozen\b|заморожен)/i`, а `EXECUTOR.md` всегда входит в эффективный `Frozen`; правка `protectedConfigFiles` разрешена только задачам высокого риска; `runAgent` добивает зависший процесс через `SIGKILL` (`killGraceMs`); git-обёртка блокирует `--output`, `-c`/`--config-env` и любые `git branch` кроме `--show-current` (Цикл 4 / S1).
- **ADR-011:** Русский текст (`SKILL.ru.md`, `EXECUTOR.ru.md`) является эталоном правил и не загружается моделями, а рабочие `SKILL.md` и `EXECUTOR.md` переводятся на английский в Цикле S5 с автотестом синхронизации структуры `E1`; раскладка по умолчанию для `--init` — `compact` (`.architect/`), `classic` сохраняется для обратной совместимости (Цикл 4 / S1).
- **ADR-012:** Порядок дорожной карты `S1`–`S5`: сначала безопасность и механика (`S1`, гибридный режим: проба `T-015` вручную + `T-016`…`T-019` через `npm run agents` по решению пользователя), затем развязка и переход на `compact` при закрытии `S2`, адаптеры (`S3`), декомпозиция ядра (`S4`) и английский перевод с выносом в чистый публичный MIT-репозиторий по отдельной команде пользователя (`S5`); после `S2`, `S3` и `S5` — приёмочная проверка в чистом репозитории другого стека без `AGENTS.md` (Цикл 4 / S1).
- **ADR-013:** `parseAgentResponse` (`adapters/agy.mjs`) принимает ответ только тогда, когда валидный корневой JSON-объект находится строго в конце `rawResponse.trim()`, логирует `discardedPrefixLength` и отклоняет обрезанный внешний JSON со вложенным объектом на конце (Цикл 5 / S2).
- **ADR-014:** Раскладка по умолчанию в `DEFAULTS` не задаётся и при отсутствии поля `layout` определяется по пути конфига (`.architect/config.json` → `compact`, `.agents/orchestrator.json` → `classic`), `--init` явно пишет `"layout": "compact"`, а этот репозиторий остаётся на `classic` для ежедневной проверки обеих раскладок (Цикл 5 / S2).
